## Operating mode after bootstrap

- All files you write outside the cognition layer + `.governor/` must
  come from an approved block manifest.
- Files inside cognition (`PROTOCOLS.md`, `protocols/**`,
  `templates/**`, etc.) can only be modified via Governor proposal +
  user approval + version bump.
- Use the manifest templates in `templates/` for every new block.
- Maintain `STATE.md` as the single source of truth for "what every
  package is doing right now."
- Maintain `governance/log.md` (append-only) with every meaningful
  Governor action.
- Use the 11 `/governor-*` slash commands (see
  `.claude/skills/governor-*/SKILL.md`) in preference to ad-hoc
  orchestrator invocations.

## Priority hierarchy

When axioms or rules conflict, resolve in this order:

1. **Correctness** (P3 green tree, Q2 invariants, T1 tenant safety).
2. **Quality** (Q1 simplicity, Q3 names, Q4 locality).
3. **Consistency** (C1 mirror, C2 minimum diff, C3 one way, C4 no debris).
4. **Token efficiency** — everything else.
