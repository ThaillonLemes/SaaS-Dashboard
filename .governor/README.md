# `.governor/` — Governor private workspace

This folder is the Workspace Governor's private notebook. Implementation
agents do not read it.

## Contents

- `README.md` — this file.
- `log.md` — append-only Governor activity log (mirrors high-level
  highlights into `governance/log.md` for the public record).
- `audits/` — pre-audit drafts and analytical notes that supplement the
  OPERATIONAL audit reports in `governance/audit-*.md`.
- `proposals/` — proposals for changes to CANONICAL files (cognition,
  axioms, schemas, orchestrator, config). Each proposal is a markdown
  file with a date prefix: `proposals/YYYY-MM-DD-<slug>.md`.
- `maps/` — per-package dependency maps and structural analyses (output
  of future `governor map` commands or hand-drawn diagrams).
- `orchestrator/` — orchestrator runtime state:
  - `.cache.json` (TRANSIENT) — regenerated by `governor scan`.
  - `.lock` (TRANSIENT) — process lock; auto-recovered after 30s.
  - `transactions/` — append-only journal of `governor integrate` and
    `governor undo` operations.

## Edit policy

Only the Workspace Governor edits inside `.governor/`. Domain Agents,
the Contracts Agent, the Database Agent, and app agents never touch
this folder.

The single exception: the orchestrator runtime writes to
`.governor/orchestrator/` as part of normal operation. Those writes are
mechanical, not authored — they're TRANSIENT or append-only journal
entries.

## Why this exists

Some Governor work is exploratory or in-progress (drafts, half-formed
proposals, analytical doodles). Mixing those with OPERATIONAL files in
`governance/` pollutes the public record. `.governor/` is the
half-finished workshop; `governance/` is the published catalog.

## Proposal lifecycle

1. Governor drafts a proposal in `.governor/proposals/YYYY-MM-DD-<slug>.md`.
2. Governor presents the proposal to the user.
3. User approves, requests changes, or rejects.
4. On approval: Governor edits the affected CANONICAL files, version-bumps,
   and records the action in `governance/log.md` (public) and
   `.governor/log.md` (private).
5. The proposal file stays in `.governor/proposals/` as a historical
   record. Rejected proposals also stay (negative space is informative).
